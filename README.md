# Gen AI Chatbot 🤖

A multi-turn AI chatbot built using Groq API and Llama 3.3 as my first Gen AI project.

## What it does
- Chats with you in a continuous conversation
- Remembers previous messages in the conversation
- Acts as a friendly Gen AI tutor

## Tech used
- Python
- Groq API
- Llama 3.3 70B model

## How to run
1. Clone this repo
2. Install dependencies
   pip install groq python-dotenv
3. Create a .env file and add your Groq API key
   GROQ_API_KEY=your-key-here
4. Run the chatbot
   python chatbot.py

## What I learned
- How conversation history works in chatbots
- How to use environment variables to protect API keys
- Tokens, context window, and temperature concepts
